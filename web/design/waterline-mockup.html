float · web UI design language · proposal

Waterline

A quieter, denser, more legible float. Everything you own sits above the line, everything you owe sits below it, and the screen spends its emphasis on what changed and what needs you. Features stay exactly as they are. This replaces the visual layer: tokens, type, a handful of primitives, and the shell.

What’s in the way today

From the current screenshots (Home, Transactions, Monthly, Portfolio, Rules, Trends).

Everything is a card

Every block is a bordered box on a blue-tinted background. With 41 <Card>s, nothing stands out, and the stat tiles on Home use three boxes to say one thing.

Numbers read like code

Amounts are set in JetBrains Mono (121 font-mono uses). They line up, but $12,450.00 looks like a log line, and mono gets mixed with prose mid-row.

Color doesn’t mean anything specific

Net worth is green because it’s net worth, and every Monthly “Net Income” cell is green too. Portfolio warnings use full-width pink and beige slabs that outweigh the data.

Account paths are the loudest text

liabilities:creditcard → expenses:groceries repeats on every row. The leaf is what you scan for, and the type (asset, expense…) is what you need to know.

Nineteen nav items, flat

Debug tools (Query, Logs, Snapshots) carry the same weight as Transactions. Adding a transaction, the most common action, has no permanent home.

Review state is hidden

Unreviewed imports show as a faint checkmark. Nothing on Home tells you there’s work waiting.

Principles

One surface

The page is paper. Separate things with space and hairlines. Fill or border only marks an object you can act on: a dialog, a notice, the selected row.

Numbers are typography

Proportional Geist with tabular figures. Big figures shrink their cents. Mono is reserved for what is literally hledger syntax: queries, regexes, raw account paths in editors.

Color carries a fact

Blue is action and assets. Teal is income arriving; transfers between your own accounts stay ink. Brick is owed or below zero. Amber is “look at this.” A number stays ink unless one of those is true.

Leaf first, type always

Show the last account segment in ink with its parents muted, plus a small glyph colored by account type, so a row can be read at a glance.

Attention is earned

Reviewed transactions carry no mark. Items that need review get a blue dot and a count in the nav. Warnings are one line, not a slab.

Dense by default

A ledger is a list. 34px desktop rows, single-line transactions, day groups instead of a date column. Room comes from removing chrome, not from padding.

Home becomes Overview. One net-worth figure with its trend, a waterline bar that shows assets against liabilities at true scale, then accounts and the month’s spending as plain lists.

Color

Cool near-white paper and a deep harbor blue taken from the logo, with lower chroma than today’s primary so it reads as ink, not as a highlight. Three semantic hues, each tied to a fact. Dark mode is a deep blue-black, not an inversion. The accent lightens and softens so it doesn’t glow.

Account-type glyphs reuse the semantic hues: assets blue, liabilities brick, income teal, expenses slate, equity violet. The existing 8-color categorical chart palette stays as is (it’s already CVD-validated). Only its use changes: categories get it, while assets, liabilities and net worth use the semantic hues.

Type

One family. Geist stays (it’s already bundled), and Geist Mono replaces JetBrains Mono so code and UI share the same metrics. Every number gets tabular-nums.

Do

  • Color a number only when it is inflow, below zero, or a change.
  • Use <Account variant="leaf"> in tables and the full path in forms.
  • Let one figure lead each page.
  • Use a Notice for anything that has a fix.

Don’t

  • Wrap a section in a Card just to give it a title.
  • Set amounts in mono or color static balances green.
  • Nest a card inside a card.
  • Add a page subtitle that repeats the title.

Navigation

Every route survives. Related pages become tabs, system pages move under one entry, and ⌘K (the existing command.jsx) jumps to any page, account or payee.

Rollout

Ordered so each step ships on its own and the Playwright screenshots stay a useful diff at every stage.

  1. Tokens and type

    • Rewrite :root / .dark in src/style.css: map shadcn vars (--background→paper, --card→paper, --popover→raised, --primary→accent, --border→rule) and add --inflow, --below, --acct-*.
    • Swap @fontsource-variable/jetbrains-mono for geist-mono, and add font-variant-numeric: tabular-nums to body.
    • This alone flattens the blue tint and shifts the palette on all 19 pages.

  2. Primitives

    • Add components/amount.jsx (wrapping formatCurrency/formatCostBasis), account.jsx, status.jsx (out of StatusButton in transaction-table.jsx), and a notice variant in ui/alert.jsx.
    • Codemod the 121 font-mono and 71 text-success/destructive call sites onto them. Keep mono where the content is hledger syntax.

  3. Shell

    • app-shell.jsx: regrouped nav, New transaction button (opens the existing AddTransactionModal), review count from a cheap status: query, ⌘K palette, and a mobile bottom bar.
    • page-header.jsx: drop the breadcrumb that repeats the title, and add an actions slot on the title row.

  4. Card audit

    • Give ui/card.jsx a variant (section by default: no border or fill, just a heading and a rule). Keep raised for genuine objects.
    • Collapse the stat-card rows on Home, Trends and Portfolio into one hero figure each.

  5. Signature screens

    • Overview hero and waterline, Transactions day grouping and leaf flow, and the Reports matrix with heat shading and tabs (Trends + Monthly), with Investments tabs (Portfolio + Lots + Prices). Routes stay put, and the tabs link to the existing paths.

  6. Charts

    • Thin 1.8px lines, an area fill on the primary series, an endpoint dot with a direct label instead of a legend where there are 3 or fewer series, and axis text in --ink-3. The Allocation half-donut becomes a single stacked bar.
